# Вклад в Fletchery Expanded

Спасибо за интерес к проекту! Ниже — как помочь с кодом, балансом, переводами или багрепортами.

## Баг-репорты

Открой [issue](../../issues) и укажи:
- версию Minecraft и загрузчика (Fabric/NeoForge), версию Fletchery Expanded
- список установленных модов (особенно если баг связан с совместимостью)
- шаги для воспроизведения
- лог из `logs/latest.log` (или crash-report из `crash-reports/`), если есть ошибка

## Идеи и предложения по балансу

Мод построен на принципе: **чем сильнее компонент — тем заметнее его недостаток или ограничение**.
Цель — чтобы все ~4000+ комбинаций компонентов оставались осмысленными, а не только "мета"-набор.
Присылая предложение по балансу, старайся описать не только силу компонента, но и его тред-офф.

## Переводы

Файлы локализации лежат в `src/main/resources/assets/fletchery_expanded/lang/<код_языка>.json`.

Чтобы добавить новый язык:
1. Скопируй `en_us.json` под нужным кодом языка
2. Переведи значения (ключи не трогай)
3. Открой Pull Request

Чтобы поправить существующий перевод — просто отредактируй нужный файл и открой PR.

## Добавление своих компонентов стрел через мод-аддон

Если ты хочешь добавить новые компоненты стрел **не меняя код самого Fletchery Expanded**, а через
отдельный мод — тебе не нужен PR сюда. Используй публичный API мода:
см. [docs/API.md](docs/API.md) и пример в [examples/example-addon](examples/example-addon).

PR в этот репозиторий нужен только если ты хочешь добавить компонент(ы) в сам Fletchery Expanded
"из коробки" (без установки отдельного аддона).

## Разработка (Pull Requests)

### Сборка

```bash
git clone https://github.com/<your-username>/fletchery-expanded.git
cd fletchery-expanded
./gradlew build
```

Требуется JDK 21+.

### Перед отправкой PR

- Убедись, что проект собирается (`./gradlew build`) без ошибок
- Проверь мод в игре (запуск клиента: `./gradlew runClient`)
- Один PR — одна логическая фича/фикс, без несвязанных изменений
- Опиши в описании PR, что изменилось и зачем

### Структура проекта (кратко)

```
src/main/java/com/fletchery/mod/
├── api/          — публичный API для аддонов (см. docs/API.md)
├── arrow/        — логика характеристик и поведения стрел
├── item/         — предметы мода
├── screen/       — GUI верстака лучника
├── registry/     — регистрация предметов/блоков/эффектов
├── compat/       — интеграции (JEI, REI, ModMenu)
├── config/       — конфигурация (Cloth Config)
└── ...
```

## Кодстайл

- Следуй существующему стилю в файле, который редактируешь
- Публичные поля/методы API (`com.fletchery.mod.api`) не должны ломать обратную совместимость без
  веской причины — при сомнениях лучше добавить новый метод, чем менять сигнатуру существующего
